Course Setup

This page collects the technical setup instructions for the seminar. You do not need previous experience with GitHub, R, or Zotero.

Before you start

Some course resources are stored in a private GitHub repository. To receive access, you first need a GitHub account.

  1. Create a free GitHub account if you do not already have one.
  2. Find your GitHub username.
  3. Send the required course registration information, including your GitHub username, to the instructors.
  4. Accept the GitHub invitation once you receive it.
  5. Continue with the setup guides below.

You can find a separate account-registration guide here: Getting Started — Social Movements in the Digital Space

When am I ready?

You are ready for the relevant course sessions when:

  • you can access the course repository;
  • you can locate the current session materials;
  • RStudio opens and the teaching dataset loads;
  • Zotero opens and can save a reference;
  • you can access the course communication platforms.

Something does not work?

Please check the troubleshooting section in the relevant setup guide. If the problem remains, contact the instructors before the session in which the software is needed.
