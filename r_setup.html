1 Before Session 3b

For the R Crash Course, you need:

  1. R
  2. RStudio Desktop
  3. the packages tidyverse and here
  4. access to the seminar repository / course files

Please complete the setup before the session.

You do not need previous programming experience.

If something does not work, do not worry about understanding the technical reason yet. Use the troubleshooting section below and contact the instructor if the problem remains.

2 Install R

R is the programming language that executes our code.

Go to the official R Project website:

Download R — The R Project

Choose a CRAN mirror and then select your operating system:

  • Windows
  • macOS
  • Linux

Install the current stable version using the normal/default installation options.

2.1 Windows

  1. Open the R download page.
  2. Choose Download R for Windows.
  3. Choose base.
  4. Download the current installer.
  5. Run the installer.
  6. Keep the default options unless you have a specific reason to change them.

2.2 macOS

  1. Open the R download page.
  2. Choose Download R for macOS.
  3. Download the installer appropriate for your Mac.
  4. Open the installer.
  5. Follow the normal installation steps.

2.3 Linux

R is available for the major Linux distributions.

Use the instructions provided through the R Project / CRAN page for your distribution.

If you already use Linux regularly, your distribution’s package manager may also provide R.

3 Install RStudio Desktop

RStudio is the program in which we will write and run most of our R code.

R and RStudio are different:

[ = ]

[ = ]

Install R first and RStudio second.

Download RStudio Desktop from Posit:

Download RStudio Desktop

Choose the free/open-source RStudio Desktop installer for your operating system and follow the standard installation process.

4 Open RStudio

After both programs are installed:

  1. Open RStudio.
  2. Wait until the Console appears.
  3. You should see information about your R version near the top of the Console.

Try:

1 + 1

You should see:

[1] 2

If this works, R and RStudio are communicating correctly.

5 Install the Packages We Need

Packages extend what R can do.

For this course we will start with:

  • tidyverse
  • here

Run the following commands in the Console:

install.packages("tidyverse")
install.packages("here")

Installation may take a few minutes.

You normally need to install a package only once on a computer.

6 Load the Packages

After installation, test that the packages load:

library(tidyverse)
library(here)

If both commands run without an error, the package setup is complete.

Remember the distinction:

install.packages("tidyverse")

means:

Download and install the package on this computer.

While:

library(tidyverse)

means:

Make the installed package available in this R session.

7 Test Your Basic Setup

Run:

library(tidyverse)
library(here)

numbers <- c(2, 4, 6, 8)

mean(numbers)

You should obtain:

[1] 5

If you do, the basic R setup is working.

10 Common Problems

10.1 there is no package called ...

For example:

there is no package called 'tidyverse'

The package has probably not been installed yet.

Run:

install.packages("tidyverse")

Then load it:

library(tidyverse)

10.2 object '...' not found

For example:

object 'posts' not found

R does not currently know an object with that name.

Check:

  • Did you run the line that creates the object?
  • Is the spelling identical?
  • Did you restart R and forget to rerun earlier code?

10.3 file does not exist

Check:

  • Is the course repository complete?
  • Did you move or rename folders?
  • Are you using the provided here() path?
  • Is the dataset inside 03b_r_crash_course/data/?
  • Did you open R from somewhere outside the course repository?

10.4 RStudio opens, but R does not work

Check that R itself is installed.

If necessary:

  1. close RStudio;
  2. install or update R;
  3. reopen RStudio.

10.5 Package installation produces lots of text

That is normal.

Installing packages can produce many lines of output in the Console.

Wait until R gives you the > prompt again.

Then test:

library(tidyverse)

10.6 RStudio asks to install additional tools

Do not install additional development tools unless the installation process specifically requires them.

For this crash course, you should normally only need:

  • R;
  • RStudio Desktop;
  • the required R packages.

10.7 Installation is blocked by your computer

If you are using a university-managed or otherwise restricted computer, you may not have permission to install software.

Please identify this before the session and contact the instructor.

11 If Local Installation Does Not Work

The preferred setup for the seminar is:

\[ \text{R} + \text{RStudio Desktop} + \text{course repository} \]

If your computer prevents a local installation, a browser-based R environment can be used as a temporary fallback.

One option is:

Posit Cloud

Posit Cloud runs an RStudio-style environment in the browser.

Important: use the local RStudio setup if possible, because that is the workflow used in the course.

If you need the browser-based fallback, contact the instructor before the session so that the course files can be set up correctly.

13 Which Resource Should I Use?
