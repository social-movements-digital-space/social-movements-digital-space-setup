1 Before You Start

The course materials are stored in a private GitHub repository.

Before you can access the repository, you need a GitHub account.

1.1 Create a GitHub Account

If you do not already have an account:

  1. Go to GitHub.
  2. Choose Sign up.
  3. Create a free account.
  4. Confirm your email address.
  5. Sign in.

You do not need a paid GitHub account for this course.

1.2 Send Us Your GitHub Username

After creating your account, find your GitHub username.

Your username appears in the URL of your GitHub profile:

https://github.com/your-username

Send the required course registration information to the instructors, including:

  • your name;
  • your GitHub username;
  • any additional information requested for the course.

Your GitHub username is required so that we can give you access to the private course repository.

1.3 Accept the Course Invitation

After we add you to the course organization, GitHub will send you an invitation.

Please:

  1. open the invitation;
  2. accept it;
  3. sign in to GitHub if necessary.

You will not be able to access the private course repository until the invitation has been accepted.

2 What GitHub Is Used For

GitHub is where we distribute course materials.

You will use it to access:

  • slides;
  • R scripts;
  • datasets;
  • exercises;
  • supporting material.

New material will be released throughout the semester.

You do not need to learn Git in detail for this course.

3 Open the Course Repository

After accepting the invitation, open the student course repository:

Social Movements in the Digital Space — Course Repository

If GitHub says that the repository does not exist or that you do not have access, check that:

  • you are signed into the correct GitHub account;
  • you sent us the correct username;
  • you accepted the GitHub invitation.

4 Recommended: Use GitHub Desktop

Because new course material will be released during the semester, the easiest workflow is to clone the repository once and update it later.

For students who have not used Git before, we recommend GitHub Desktop.

Download it from:

GitHub Desktop

Install the program using the normal installation procedure for your operating system.

4.1 Clone the Course Repository

After installing GitHub Desktop:

  1. open GitHub Desktop;
  2. sign in with the same GitHub account you use for the course;
  3. choose File → Clone repository;
  4. choose the course repository;
  5. select a location on your computer;
  6. choose Clone.

For example:

Documents/
└── course-repository/

The exact name of the outermost folder may differ.

Please keep the folders inside the repository unchanged.

5 Getting New Course Material

You only need to clone the repository once.

When new material is released:

  1. open GitHub Desktop;
  2. select the course repository;
  3. choose Fetch origin;
  4. if changes are available, choose Pull origin.

This updates your local copy with newly released course material.

6 Alternative: Download ZIP

If GitHub Desktop does not work, you can download the repository manually.

On the GitHub repository page:

  1. click Code;
  2. choose Download ZIP;
  3. unzip the downloaded file;
  4. save the folder somewhere you can find again.
Note

If you use Download ZIP, your local copy does not update automatically.

When new material is released later in the semester, you may need to download the repository again.

7 Optional: Clone with Git

If you already use Git from the command line, you can clone the repository directly:

git clone https://github.com/social-movements-digital-space/social-movements-digital-space-students-2026.git

You do not need to use command-line Git for this course.

9 Keep the Repository Structure Intact

Please:

  • do not rename the course folders;
  • do not move individual datasets elsewhere;
  • do not move scripts away from their session folders;
  • keep the repository structure intact.

This helps the R exercises locate files consistently.

10 Important: Course Materials Are Released Gradually

The repository may not contain every future session yet.

This is intentional.

Course materials will be released according to the seminar schedule, and solutions may be added after the corresponding session.
