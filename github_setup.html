1 What GitHub Is Used For

GitHub is where the course materials are stored.

You will use it to access:

  • slides;
  • R scripts;
  • datasets;
  • supporting material.

You do not need to learn Git in detail for this course.

2 Open the Course Repository

Course repository:

Social Movements in the Digital Space — GitHub

3 Get the Course Files

3.1 Easiest option: Download ZIP

On the GitHub repository page:

  1. click Code;
  2. choose Download ZIP;
  3. unzip the folder;
  4. save it somewhere you can find again.

For example:

Documents/
└── social_movements_digital_space/

Do not move individual scripts or data files out of the repository.

Keeping the folder structure intact helps the R code find the correct files.

3.2 Optional: Clone with Git

If you already use Git, you can clone the repository instead:

git clone https://github.com/NikolinaFiliposki/social-movements-digital-space-2026.git

You do not need this option for Session 3b.

4 Find the Session 3b Files

The relevant folder is:

social_movements_digital_space/
└── 03b_r_crash_course/
    ├── code/

For the R Crash Course, you will mainly use:

03b_r_crash_course/
├── code/

└── data/
    └── bluesky_climate_sample.csv

5 Important

Please:

  • keep the repository folder structure intact;
  • do not rename the course folders;
  • do not move the dataset away from the data folder;
  • open the provided R script rather than creating a new empty file.
