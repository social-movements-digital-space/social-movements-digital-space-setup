## Dataset

The exercises use prepared teaching subsets derived from the
[Two Million Bluesky Posts](https://huggingface.co/datasets/alpindale/two-million-bluesky-posts)
dataset published by `alpindale` on Hugging Face.

The original dataset contains approximately 2.1 million Bluesky posts.

For this course, smaller subsets were prepared so that the exercises can be completed locally and the relevant concepts can be explored without loading the full dataset.

The teaching files used in this session are:

- `bluesky_climate_sample.csv`
- `bluesky_movements_sample.csv`

See `data/codebook.md` for information about the variables.
